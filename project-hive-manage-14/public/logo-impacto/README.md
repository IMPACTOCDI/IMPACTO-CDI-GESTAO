# Logo IMPACTO

Coloque o arquivo da logo da IMPACTO Consultoria e Desenvolvimento Institucional neste diretório.

**Nome do arquivo:** `logo.png`

**Formato recomendado:** PNG com fundo transparente

**Tamanho recomendado:** 
- Para uso geral: 512x512px ou maior
- A logo será redimensionada automaticamente conforme necessário

**Onde a logo será usada:**
- Página de Login
- Página de Registro
- Barra de navegação (Navbar)
- Favicon do navegador
- Meta tags para compartilhamento em redes sociais
